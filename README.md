# SUPER KIT DE ATIVIDADES INFANTIS

Página de vendas estática para publicar no GitHub Pages ou Vercel.

## Antes de publicar
1. Crie o produto na Hotmart e configure a entrega dos quatro PDFs na área de membros/entrega.
2. Copie o link público do checkout Hotmart.
3. Abra `index.html` e substitua `COLE_AQUI_SEU_LINK_DE_CHECKOUT_HOTMART` pelo link real.
4. Confirme se a oferta realmente inclui os quatro materiais e se você tem autorização para comercializar cada arquivo.

## Publicar no GitHub
1. Entre em https://github.com e crie um repositório público, por exemplo `super-kit-atividades-infantis`.
2. Envie `index.html`, `styles.css` e a pasta `assets`.
3. Faça commit das alterações.

## Publicar na Vercel
1. Entre em https://vercel.com e conecte sua conta GitHub.
2. Clique em Add New > Project e importe o repositório.
3. Não é necessário framework nem build command. Deixe o diretório raiz como `./`.
4. Clique em Deploy.

## Observações
- Os PDFs não estão incluídos no site e não devem ser publicados em repositório público. Configure a entrega na Hotmart.
- As capas em SVG são ilustrações de apresentação, não reproduções das capas originais dos PDFs.
- O site não confirma compra nem libera arquivos por conta própria; isso é feito pela Hotmart.
- A oferta usa R$ 19,90 conforme informado pelo vendedor. Revise regras, direitos de uso e descrição antes de anunciar.
