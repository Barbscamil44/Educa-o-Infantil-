Página de vendas estática para publicar no GitHub Pages ou Vercel.

## Observações
- Os PDFs não estão incluídos no site e não devem ser publicados em repositório público. Configure a entrega na Hotmart.
- As capas em SVG são ilustrações de apresentação, não reproduções das capas originais dos PDFs.
- O site não confirma compra nem libera arquivos por conta própria; isso é feito pela Hotmart.
- A oferta usa R$ 19,90 conforme informado pelo vendedor. Revise regras, direitos de uso e descrição antes de anunciar.
